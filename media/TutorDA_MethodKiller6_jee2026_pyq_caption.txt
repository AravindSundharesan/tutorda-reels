JEE Main 2026, 23 January, Shift 1: f(x) = ∫ (2 − x²)eˣ / (√(1 + x)(1 − x)^(3/2)) dx, f(0) = 0. Find f(1/2). By parts with u = the whole fraction makes u′ a monster.

Here's the shortcut for this integration: eˣ(f + f′) = (eˣf)′, the product rule run backwards. It only works when the bracket is exactly f + f′.

How do you guess f? The (1 − x)^(3/2) downstairs is the clue: differentiating 1/√(1 − x) gives 1/(2(1 − x)^(3/2)). So f is a root over 1 − x. Try f = √((1 + x)/(1 − x)). Its derivative is f′ = 1/(√(1 + x)(1 − x)^(3/2)). Put f + f′ over that denominator and the top becomes (1 − x²) + 1 = 2 − x², exactly the question.

So f(x) = eˣ√((1 + x)/(1 − x)) + C. At x = 0 that gives 1 + C, and f(0) = 0, so C = −1. At x = 1/2: f(1/2) = √(3e) − 1.
